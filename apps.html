Apps Revon plays well with

App integrations

Revon supports Shopify's app block system, so most apps drop in without any code editing. Here's how the most commonly asked-about apps work with the theme.

How Revon works with apps

Modern Shopify apps come with app blocks. From the theme editor, click Add block inside any section that supports them (product page, featured products, cart, and most content sections), and the app's blocks appear in the picker. No code needed.

If an app doesn't have an app block (older apps especially), you can drop its code snippet into a Custom Liquid block or section. See Customizing → Product page blocks for where to add Custom Liquid.

Good to know

App stability across theme updates depends on the app, not the theme. If you switch themes (or update Revon to a new version), the app's blocks travel with the app, not with the theme. You'll need to re-add them once.

Email marketing

Klaviyo

Best-known email and SMS platform for Shopify. Works with Revon out of the box via Klaviyo's app blocks (newsletter signup, abandoned cart, etc).

Setup: Install Klaviyo from the Shopify App Store and link your store. In the theme editor, you can add Klaviyo's signup forms via app block to any section. Revon's built-in Newsletter section also writes to Shopify's customer database, which Klaviyo syncs from automatically.

Mailchimp

Email marketing with a generous free tier.

Setup: Install Mailchimp for Shopify, link your audience. Like Klaviyo, Mailchimp syncs subscribers from Shopify's customer database, so Revon's Newsletter section just works. For custom Mailchimp forms, paste the embed code into a Custom Liquid block.

Omnisend

Email + SMS, popular alternative to Klaviyo.

Setup: Install Omnisend, connect your store, and use its app blocks for popups and inline forms. The Revon Newsletter section is also compatible.

Subscriptions

Revon supports Shopify's native selling plans, which is what every modern subscription app uses. Subscription options appear automatically on the product page and in the cart — no theme setting to toggle.

Shopify Subscriptions

Shopify's own first-party subscription app. Free, simple, and supported natively.

Setup: Install Shopify Subscriptions from the App Store, create a selling plan, assign it to products. Revon renders the subscribe / one-time radio buttons on the product page automatically.

Recharge

The most mature subscription platform on Shopify, with deep customization.

Setup: Install Recharge and set up your subscription plans. Recharge uses Shopify selling plans, so Revon picks them up automatically. Recharge's customer portal opens in their hosted page by default.

Bold Subscriptions

Long-standing subscription app with a Shopify-native version.

Setup: Install Bold Subscriptions V2 (the version that uses Shopify selling plans). Once installed, Revon's product page shows subscription options automatically.

Loop Subscriptions

Newer subscription app focused on retention and analytics.

Setup: Same as the others — install, set up plans, and Revon renders them. Loop's customer portal can be embedded via an app block.

Reviews

Judge.me

The most popular reviews app on Shopify, with a generous free plan.

Setup: Install Judge.me. In the theme editor, add the Judge.me app blocks to:

  • Product page — the review widget block (full reviews list) and the star rating block (in the info column)
  • Homepage — the reviews carousel block
  • Product card — the star rating preview block

No code editing needed.

Loox

Photo-first review platform — customers attach pictures of their purchases.

Setup: Install Loox. App blocks are available for the product page (review widget, star rating, gallery) and for any content section (Loox photo grid). All drop in via the theme editor.

Yotpo Reviews

Enterprise-grade reviews with deep loyalty and SMS add-ons.

Setup: Install Yotpo Reviews and follow their onboarding. App blocks available for product page and homepage widgets.

Loyalty & rewards

Smile.io

Friendliest loyalty app on Shopify, with a free tier.

Setup: Install Smile, configure rewards. The Smile launcher (the small "Rewards" button) appears automatically on every page once enabled. App blocks available for displaying points on the cart, product page, or customer account.

LoyaltyLion

More customizable loyalty platform, used by larger merchants.

Setup: Install LoyaltyLion and follow their setup. The points panel adds via an app block; customer-facing widgets are also app blocks.

Wishlists

Wishlists aren't built into Revon — they require an app. Both options below add a heart icon to product cards and a dedicated wishlist page.

Wishlist Plus (Swym)

The most-installed wishlist app, free for the first 500 wishlist items per month.

Setup: Install Wishlist Plus. The heart icon adds to product cards via an app block. The wishlist page is hosted by Swym and linked from your storefront automatically.

Smart Wishlist

Simpler alternative, fully free.

Setup: Install and follow the app's instructions to enable on product pages.

Live chat & helpdesk

Shopify Inbox

Shopify's free first-party chat app.

Setup: Install Shopify Inbox. The chat bubble appears automatically in the bottom-right of every page. No theme editing.

Gorgias

Helpdesk and live chat used by mid-to-large Shopify merchants.

Setup: Install Gorgias and follow their onboarding. The chat widget adds automatically. Optional app blocks let you embed a contact form into Revon's Contact page.

Tidio

Free chat with AI bot features.

Setup: Install Tidio. The chat bubble adds via their app — no manual placement needed.

Search

Revon uses Shopify's built-in predictive search by default, which is fine for most small to mid-sized stores. For larger catalogs (5000+ products) or advanced filters, an app helps:

Shopify Search & Discovery

Shopify's free app for filter synonyms, search rules, and product recommendations.

Setup: Install it from the App Store. It runs in the background and improves results from the default Revon search bar automatically.

Algolia / Klevu / Searchanise

Third-party search engines for very large stores.

Setup: Each app provides its own embedded search widget that replaces Revon's predictive search. Follow the app's instructions to enable. You may need to disable Revon's predictive search via theme settings to avoid two search results showing.

App not listed?

If the app has an app block, it almost certainly works with Revon out of the box. Click Add block inside the relevant section in the theme editor and look for the app's blocks in the picker.

If the app needs a code snippet, drop it into a Custom Liquid block or section. No theme file editing required.

If the app modifies the cart or checkout in unusual ways (e.g. some upsell apps or inventory countdown timers), it may need theme-level integration. Contact support if you're not sure — let us know the app name and we'll point you at the right setup.
