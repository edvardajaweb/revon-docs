Installation & updates

How do I install Revon on my store?

After purchasing from the Shopify Theme Store, Revon is added to your theme library automatically. Go to Online Store → Themes, find Revon in your library, and click Add. See the Getting started guide for step-by-step instructions.

How do I update Revon to a new version?

When a new version ships, Shopify notifies you on the Themes page. Click Update and Shopify will add the new version as a separate theme alongside your current one. Your settings don't migrate automatically — you'll need to reconfigure essentials like logo, fonts, and colors. This is by design so custom code changes aren't overwritten.

Will I lose my customizations when I update?

Settings made through the theme editor (section content, colors, fonts) don't automatically carry over to a new version. Code customizations you've made directly to theme files will also not carry over. We recommend duplicating your current theme before updating so you have a stable fallback.

Do I need a developer to install or set up Revon?

No. Revon is designed to be set up entirely through the Shopify theme editor — no Liquid or CSS edits required for the standard configuration. A developer only becomes useful if you want custom sections, deep code modifications, or app integrations beyond what app blocks provide.

Presets

What is a preset?

A preset is a named bundle of theme settings — typography, color palette, spacing, motion, cart type — plus a curated homepage layout. Revon ships with three: Skincare (beauty/wellness), Atelier (slow fashion), and Maison (home/lifestyle). Each is a complete starting point tuned for a different industry. See the Presets page for a full comparison.

Which preset is the default?

Maison is selected as the default preset on a fresh install. You can switch to Skincare or Atelier at any time from the theme editor under Theme settings → Theme styles.

How do I switch between presets?

In the theme editor, click Theme settings (top-left), open the Theme styles picker at the top, and choose a different preset. Save. The theme settings switch immediately and the homepage refreshes with the matching layout. Section content you've already customized is preserved.

Will switching presets erase my work?

Switching a preset overwrites your theme settings (colors, fonts, spacing, etc.) with that preset's defaults. It does not overwrite your section content, products, collections, or templates. Always duplicate your theme before switching if you've spent significant time tuning settings — that way you have a clean rollback.

Can I use sections from one preset on another?

Yes. All 62 sections work on all three presets. You can pull "Clinical results" from Skincare into Atelier, drop "Lookbook grid" from Atelier into Maison, or any other combination. Presets only define defaults, not restrictions.

Can I make my own preset?

For most stores, picking one of the three built-in presets and tweaking the theme settings is enough — you don't need a custom preset. If you do want a saved, named style (for example, because you run more than one store), this needs code editing. A developer can do it in a few minutes — see Customizing → Saving a custom preset for the steps.

Demo content & images

Does the demo store content come with the theme?

No. The Theme Store does not transfer demo store products, collections, or images when you install a theme. You'll need to add your own. Each preset's homepage layout ships with image placeholder slots that mirror the demo, so once you replace the placeholders with your own content the theme will look similar.

Where can I find royalty-free images?

We recommend Shopify Burst for free high-quality product and lifestyle photos. Unsplash and Pexels are also good options. All three are free for commercial use without attribution.

What image sizes should I upload?

For product images, upload the largest version you have — Shopify generates responsive sizes automatically and Revon uses srcset to pick the right one. Aim for at least 2000px on the longest edge. For section backgrounds (hero, parallax), 2400×1500 is a safe minimum. Revon uses image.presentation.focal_point so you can set the crop center in Shopify's image editor.

How do I set image focal points?

In your Shopify admin, open any image (product or file). Click Edit → drag the focal-point indicator to the part of the image you want kept in view when cropped. Revon respects this on every responsive image — product cards, heroes, lookbooks, etc.

Customization

How do I change fonts?

Open Theme settings → Typography. Revon has four font pickers: heading, body, editorial, and handwritten. Each accepts any font in the Shopify font picker (system fonts, Google Fonts, and any font uploaded via Shopify Admin). Bold and italic variants load automatically.

How do I change colors?

Open Theme settings → Colors. Each preset defines two color schemes (a light and a dark) — edit any color and the change applies everywhere that uses that scheme. Individual sections can opt into a different scheme via the section's Color scheme setting, so you can alternate light and dark blocks down a page.

How do I add variant color swatches?

Revon uses Shopify's native swatch system. In your Shopify admin, go to Settings → Custom data → Products → Variant options, and set a color or image for each option value. Revon will render them automatically on product cards and product pages. Names it doesn't recognize fall back to a neutral grey circle.

Can I use a different menu for navigation?

Yes. In the theme editor, click the Header section and change the Menu setting to any menu you've created in Online Store → Navigation.

How many levels does the dropdown menu support?

Revon supports up to two levels of nested navigation. Create sub-items in Shopify's menu editor and drop them onto a parent item to nest. The header renders the second level as a full-width megamenu panel on desktop and as an indented accordion in the mobile drawer.

How do I disable the cookie banner?

Open Theme settings → Advanced and toggle off Show cookie banner. Note that some regions (notably the EU under GDPR) require some form of cookie consent — Shopify's built-in cookie banner under Settings → Customer privacy may be a better fit if you sell internationally.

Premium sections

How does the cinematic hero work?

Cinematic hero is a full-viewport section that accepts either a looping video (.mp4, .webm) or a static image as the background. On top you get a morphing headline (two heading fields that cross-fade), eyebrow, body copy, two CTAs, and an optional scroll indicator. Add it from Add section → Cinematic hero. The video plays muted and loops; provide a poster image for the first paint.

What's the difference between Cinematic hero and Editorial hero?

Cinematic hero is full-bleed video/image with overlay text — great for beauty and lifestyle brands wanting maximum impact. Editorial hero is magazine-style: a more constrained layout with serif typography, a bold heading, an italic accent line, and a content block stack underneath. Editorial hero suits fashion and home brands that lead with type over imagery.

How do I set up the Before/After slider?

Add a Before / after section and upload two images of identical dimensions — one labeled "Before", one labeled "After". The section renders a draggable handle that wipes between them. Add multiple Before/After pairs as repeating blocks for a stack of comparisons.

How do Shop the look hotspots work?

Add a Shop the look section, upload a lifestyle image, then add hotspot blocks. Each hotspot has an X/Y position (as a percentage), a product picker, and an optional label. On the storefront, the hotspot renders as a clickable dot — clicking it opens a quick-view card with the product and an add-to-cart button. Up to eight hotspots per image.

How do I configure Clinical results / Key ingredients?

Both are repeating-block sections. For Clinical results, each block holds a stat value ("97%"), a one-line claim, and an optional source. For Key ingredients, each block holds an ingredient name, image, description, and an optional "Found in" link to a related product or collection. Both sections are designed for skincare / wellness storytelling but work for any merchant who wants stat- or ingredient-driven proof.

Products & cart

Does Revon support subscriptions?

Yes. Revon supports Shopify's native selling plans. Any subscription app that uses Shopify selling plans (Shopify Subscriptions, Recharge, Loop, Bold, etc.) will work with Revon automatically. Subscription options appear on the product page and in the cart with the discount applied.

Does Revon support 3D models and video?

Yes. Upload a .glb file or a video file to the product's media in the Shopify admin, and Revon will render it in the product gallery alongside images. The 3D viewer uses Shopify's model-viewer component with AR support on mobile.

How do I enable Shop Pay Installments?

Shop Pay Installments appear automatically on the product page when your store qualifies. There is no theme setting to toggle — it's controlled by your payment provider and eligibility. Currently US-only.

Cart drawer or cart page — which should I pick?

Drawer keeps customers in-flow — they add an item, see the drawer slide in, and continue shopping. Page is better if you have a complex cart (gift wrapping, custom notes, upsells) that benefits from a dedicated screen. Set the preference under Theme settings → Cart → Cart type. The cart page is always accessible at /cart regardless.

How does the free-shipping bar work?

Set a threshold under Theme settings → Cart → Free shipping threshold (in your store currency, before tax). The cart drawer and cart page render a progress bar showing how much more the customer needs to add. The bar is informational — actual free shipping is configured under Shopify Admin → Settings → Shipping.

How does the gift card page work?

When a customer buys a gift card product, they're sent a custom-styled gift card page with the code, a QR code (for in-store redemption if applicable), Apple Wallet support, and a personalized message. The gift card product page also has a recipient form so buyers can send the gift card directly to someone else's email on a scheduled date.

Languages & currencies

Does Revon support multiple languages?

Yes. Revon ships with English (default), German, Spanish, and French translations of all merchant-facing strings. Additional languages can be added by duplicating locales/en.default.json and translating the values. When you sell in multiple languages, Revon shows a language selector in the footer and mobile menu.

Does Revon support multiple currencies?

Yes. When you enable Shopify Markets and sell in multiple currencies, Revon shows a country selector in the footer and mobile menu. Prices update automatically based on the customer's selection. The selector can be hidden via theme settings if you only sell in one currency.

How do I add a custom language?

Revon ships with English, German, Spanish, and French. To add another language without any code, install Shopify's free Translate & Adapt app (or any other Shopify translation app) and translate the storefront from inside the app. A developer can also add a new language file directly in the theme code if you prefer that route.

Performance & accessibility

How is the theme's performance?

Revon is optimized for Shopify's performance benchmarks. It uses lazy-loaded images, deferred scripts, font preloading, and native browser features instead of heavy JavaScript libraries. Critical CSS is split out and inlined; non-critical CSS loads after. Your actual Lighthouse score will depend on the apps you install and the size of the images you upload.

Will animations slow down my Lighthouse score?

The default animation budget is conservative — fade-ups and crossfades, no continuous layout shifts. If you're seeing performance issues, the most common cause is heavy product imagery or third-party app scripts, not the theme's animations. You can disable all animations via Theme settings → Animations and effects → Enable animations.

Is Revon accessible?

Yes. Revon is designed to meet WCAG 2.1 AA. All interactive elements are keyboard accessible, focus states are visible, forms have proper labels, decorative SVGs are aria-hidden, and text colors meet contrast requirements. The theme respects prefers-reduced-motion for animations. If you find an accessibility issue, please report it.

Apps & integrations

Does Revon work with my favorite app?

Most Shopify apps work with Revon out of the box via app blocks. Revon supports app blocks in the product page, featured products section, cart, and most other sections. If an app you need doesn't have an app block, add a Custom Liquid block to the relevant section and paste the app's snippet there.

How do I add a wishlist, reviews, or loyalty program?

These features aren't built into Revon — they require an app. Shopify's App Store has free and paid options for each. Most of them ship with an app block that drops into Revon without code changes. Tested integrations include Judge.me and Loox for reviews, Smile.io for loyalty, and Wishlist Plus for wishlists.

Does Revon work with Klaviyo / Mailchimp?

Yes. The Newsletter section uses Shopify's native customer subscription, which both Klaviyo and Mailchimp can sync from. For their own embed forms (e.g. multi-step signup), use a Custom Liquid block in any section and paste the form snippet.

Can I get a refund?

Refund policies for themes are handled by Shopify directly. See Shopify's theme refund policy for details.
