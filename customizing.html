Customizing Revon

Revon comes with 62 sections and three ready-made styles, all built on Shopify's Online Store 2.0. Everything on this page can be added, removed, or changed from the theme editor — no code needed.

Theme settings

Click Theme settings in the top-right of the theme editor to control site-wide options. When you apply a preset, Revon fills in these settings for you. You can change anything afterwards.

Colors

Revon uses color schemes — each scheme is a named bundle of seven colors (background, surface, text, secondary text, border, button bg, button text). Every section can pick its scheme, so you can alternate light and dark blocks down a page. All defaults meet WCAG 2.1 AA contrast.

Typography

Four global font pickers control the entire theme: heading, body, editorial, and handwritten. Bold and italic variants load automatically. The full Shopify font picker is supported (system fonts, Google Fonts, and uploaded fonts via Shopify Admin).

Layout

  • Page width — 1200, 1400, or 1450px container
  • Section spacing — global top/bottom padding (desktop and mobile values, in px)
  • Border radius — sharpen or soften corners on buttons, cards, media, and inputs independently

Animations & effects

  • Loading effect — fade, fade-up, slide, or none for scroll reveals
  • Page transitions — smooth transitions between pages (Lenis-driven)
  • Image hover — subtle zoom/swap on product cards
  • Loading bar — slim progress indicator at the top of the page
  • Scroll progress — vertical progress meter on long pages

Cart

  • Cart type — drawer or page
  • Free shipping threshold — shows a progress bar
  • Cart notes — let customers leave a note on their order
  • Gift wrapping — optional paid add-on as a checkbox

SEO & social sharing

  • Default social share image — 1200×630 OG fallback for pages without their own image
  • Default meta description — used on pages without one
  • Twitter handle — populates twitter:site

Hero sections

Full-bleed sections designed for the top of the page.

  • Cinematic hero — a full-screen video or image with a headline that fades between two lines and a scroll arrow. The main opener for the Skincare and Maison presets.
  • Editorial hero — magazine-style hero with eyebrow, bold heading, italic serif accent, and a content block stack. The Atelier preset's default opener.
  • Hero slider — multi-slide carousel with autoplay, dots, and per-slide content.
  • Split banner — image + text in a 50/50 or 60/40 split. Good for category pages.
  • Video feature — full-bleed looping video with overlaid text.

Product display

  • Featured products — hand-picked product row or grid. Choose a collection or a fixed list.
  • Product showcase — single-product editorial layout with sprite animation and feature blocks.
  • Product editorial — long-form product story with imagery, copy, and inline buying.
  • Product marquee — infinite-scroll product ticker.
  • Product recommendations — automated cross-sell row via Shopify's recommendations API.
  • Recently viewed — customer's recent browse history.
  • Shop the look — clickable hotspots on a lifestyle image. Up to 8 hotspots per image.
  • Collection list — featured collection tiles with image, name, and CTA.

Brand storytelling

  • Rich text — heading + body content. The all-purpose copy block.
  • Image with text — classic side-by-side image and copy.
  • Editorial scroll — long-form article layout for deeper storytelling.
  • Editorial mosaic — magazine-style multi-image grid with text annotations.
  • Editorial statement — large quote or manifesto display.
  • Key ingredients — annotated ingredient cards with imagery (skincare / wellness).
  • Clinical results — stat-driven proof points (e.g. "97% reported smoother skin").
  • Before / after — drag-slider image comparison.
  • Mood routines — multi-step routine builder with product callouts.
  • Timeline — chronological brand history rendered as a vertical column.
  • Stats — animated number counters with labels.

Galleries

  • Image gallery — multi-image grid with configurable columns.
  • Lookbook grid — masonry-style lifestyle photography.
  • Rhythm board — Pinterest-style moodboard layout.
  • Room plan — interior layout / floorplan with product callouts (Maison-flavored).

Social proof

  • Testimonials — customer quotes with optional photo and star rating, auto-rotating slider.
  • Brand logos — press, partner, or stockist logos in a uniform grid.
  • Social feed — curated grid of lifestyle images with external links (manual, not API-driven).

Engagement & conversion

  • Newsletter — email signup using Shopify's native customer subscription.
  • Contact form — standard Shopify contact form with name, email, message, and optional fields.
  • FAQ — collapsible question and answer list with smooth expand animation.
  • Comparison table — feature comparison grid (e.g. Revon vs. competitors).
  • Features grid — icon-and-text grid for shipping, returns, guarantees.
  • Countdown — tied to a real merchant-chosen date. No fake urgency — when the date expires, the section disappears.
  • Blog carousel — recent blog posts in a horizontal carousel.

Motion & dividers

  • Marquee — infinite horizontal text ticker.
  • Horizontal scroll — horizontally-scrolling cards with snap points.
  • Parallax image — full-width image with scroll-driven parallax depth.
  • Scroll text — large scroll-triggered text reveal (one word at a time).
  • Gradient divider — colored separator block to break up sections.

Site-wide controls

Sections that live in the header or footer section groups, or render globally.

  • Announcement bar — top promo banner. Up to three rotating messages with optional links.
  • Header — logo, menu (up to two levels), search, account, cart. Sticky on scroll.
  • Footer — multi-column footer with menus, newsletter, social, payment icons, locale selector.
  • Age verifier — 18+/21+ gate for alcohol, supplements, etc. Stores acceptance in a cookie.
  • Maison promo popup — themed popup tuned to the Maison preset (timed offer, mood image).
  • Popup — generic newsletter or discount popup with configurable triggers.
  • Cart notification — toast that fires after add-to-cart, with the added product.
  • Custom section — empty section accepting custom Liquid for app integrations or one-off layouts.

Main page sections

One per page type. These are the JSON-driven main bodies of each template.

  • main-product — the product page (gallery + info column with blocks).
  • main-collection — collection grid with filters, sort, and pagination.
  • main-cart — full-page cart with line items, discounts, accelerated checkout.
  • main-blog — blog index with article cards.
  • main-article — single article with author, date, content, and comments.
  • main-page — generic CMS page wrapper.
  • main-search — search results page (products + articles).
  • main-404 — 404 error page with helpful return links.
  • main-password — coming-soon / password-protected store page.

Product page blocks

On the product page, every element in the info column is a block you can reorder or remove:

  • Vendor
  • Title
  • Price (with unit price and tax-included note)
  • Inventory status
  • Description
  • Benefits list
  • Variant picker (with swatches)
  • Quantity selector
  • Buy buttons (add-to-cart, dynamic checkout, accelerated checkout)
  • Follow on Shop
  • Shop Pay Installments banner
  • Complementary products
  • Trust badges / feature icons
  • Delivery estimate
  • Size guide modal
  • Share buttons
  • Popup blocks (materials, care, shipping info)
  • Tabs (description, materials, shipping, etc. — used on product.with-tabs)
  • Custom Liquid block — paste in any app snippet
  • App blocks — drop in any compatible Shopify app block

Variant swatches

Revon uses Shopify's native swatch object. To set a swatch color or image for a variant option value:

  1. In Shopify admin, go to Settings → Custom data → Products → Variant options.
  2. Add or edit the option value to attach a color or image swatch definition.
  3. Revon picks it up automatically on product cards and product pages.

If no swatch is configured, Revon falls back to a built-in color-name-to-hex map for common names like Black, Cream, Navy, Sage, etc. Names it doesn't recognize render as a neutral grey circle with the name beside it.

Custom code

Before editing code

Always duplicate your theme from the Shopify admin so you have a rollback. Code customizations may not carry over to a future Revon update. If you're not comfortable editing Liquid or CSS, consider hiring a Shopify Partner.

Adding custom CSS

  1. Open Online Store → Themes → Edit code.
  2. Open assets/critical.css (or modern.css for non-critical styles).
  3. Add your rules at the bottom of the file.
  4. Save — changes go live immediately.

Adding custom Liquid

You don't need to edit section files to add custom snippets. Use the Custom Liquid block available in the product section and most content sections, or add a Custom section anywhere on a template.

Saving a custom preset

If you've configured the theme to a state you want to reuse on another store:

  1. Open config/settings_data.json via the code editor.
  2. Find the presets object and copy one of the existing entries (Skincare, Atelier, or Maison) as a starting point.
  3. Rename the key and adjust the values to match your customization.
  4. Save. Your preset shows up in the theme editor's preset picker.
