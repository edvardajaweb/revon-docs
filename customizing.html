Customizing Revon

Revon is built on Online Store 2.0, so you can customize nearly every page visually — no code required. This page covers sections, blocks, and theme settings.

Theme settings

Open Theme settings from the top-right of the theme editor to control site-wide options. Highlights:

Colors

Revon exposes a full color system — background, text, accent, border, muted, surface, and badge colors. Change any value and the whole theme updates. All colors meet the WCAG 2.1 AA contrast ratio in the default palette.

Typography

Pick a heading font and a body font. Revon loads bold, italic, and bold-italic variants automatically, so you don't need to upload any custom files. Every font Shopify supports is compatible, including the full Google Fonts library.

Layout

  • Container width — narrow, medium, or wide
  • Section spacing — adjust top and bottom padding globally
  • Border radius — sharpen or soften corners on buttons, cards, and images

Cart

  • Cart type — drawer, page, or modal
  • Free shipping threshold — shows a progress bar in the drawer
  • Cart notes — let customers leave a note on their order
  • Gift wrapping — optional paid add-on that appears as a checkbox

Sections

Revon ships with 60+ sections, each purpose-built for a real merchandising scenario. You can add, remove, and reorder sections on any template. Here are some highlights:

Hero sections

  • Cinematic hero — full-viewport hero with parallax and overlay text
  • Slideshow — multi-slide carousel with autoplay and dots
  • Split hero — image + text, 50/50 or 60/40 split
  • Video banner — full-bleed looping video

Product display

  • Featured products — hand-picked product row or slider
  • Featured collection — grid of products from a single collection
  • Product showcase — single-product editorial layout
  • Product marquee — infinite-scroll product row
  • Shop the look — hotspots on a lifestyle image
  • Lookbook grid — masonry grid of lifestyle photography

Brand storytelling

  • Image with text — classic side-by-side
  • Editorial scroll — long-form article layout
  • Key ingredients — annotated ingredient breakdown
  • Clinical results — chart and statistics display
  • Timeline — brand history timeline
  • Stats — animated number counters
  • Text reveal — scroll-triggered text animation

Social proof

  • Testimonials — customer quotes with optional photo
  • Brand logos — press and partner logos
  • Social feed — curated grid of lifestyle images with links

Supporting content

  • FAQ — collapsible question and answer list
  • Comparison table — feature comparison grid
  • Features grid — icon-and-text grid
  • Countdown — tied to a real merchant-chosen date (no fake urgency)
  • Map — embedded location map
  • Newsletter — email signup form
  • Contact form — standard Shopify contact form

Product page blocks

On the product page, every element in the info column is a block you can reorder or remove:

  • Vendor
  • Title
  • Price (with unit price and tax-included note)
  • Inventory status
  • Description
  • Benefits list
  • Variant picker (with swatches)
  • Buy buttons (quantity, add-to-cart, accelerated checkout)
  • Complementary products
  • Trust badges
  • Delivery estimate
  • Size guide
  • Share
  • Popup (materials, care, shipping info)
  • Custom liquid blocks for app integrations
  • App blocks — drop in any compatible Shopify app

Variant swatches

Revon uses Shopify's native swatch object. To set a swatch color or image for a variant option value:

  1. Go to Settings → Metafields → Products.
  2. Create or edit the product option value to add a swatch definition (color or image).
  3. Revon will pick it up automatically on the product and collection pages.

If no swatch is configured, Revon falls back to a built-in color-name-to-hex map for common names like Black, Navy, Cream, etc.

Custom code

Warning: Before editing code, always duplicate your theme from the Shopify admin so you have a backup. Code customizations may not carry over when you update Revon to a new version. Consider hiring a Shopify Partner if you're not comfortable editing Liquid.

Adding custom CSS

  1. Open Online Store → Themes → Actions → Edit code.
  2. Navigate to assets/base.css.
  3. Add your custom rules at the bottom of the file.
  4. Save — changes go live immediately.

Adding custom Liquid

You don't need to edit section files to add custom snippets. Use the Custom liquid block available in most sections (including product and featured products), or add a Custom liquid section anywhere on a template.
