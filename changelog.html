v1.0.0
May 2026

Initial release

The first public release of Revon, built from the ground up for the Shopify Theme Store. Ships with three industry-tuned presets, 62 hand-built sections, full Online Store 2.0 support, and every feature required by Shopify's Theme Store guidelines.

Three presets

  • Skincare — beauty / wellness / fragrance. Bold uppercase Manrope, warm cream palette, signature sections: Clinical results, Key ingredients, Before/after, Mood routines.
  • Atelier — slow fashion / capsule wardrobes / jewelry. Light Cormorant serif, paper-grey palette, signature sections: Editorial mosaic, Editorial statement, Lookbook grid, Timeline.
  • Maison — home / lifestyle / interiors (default preset). Noto Serif body, sage-cream palette, signature sections: Room plan, Rhythm board, Editorial scroll, Parallax image.

Section library — 62 sections

  • 5 hero sections — Cinematic hero, Editorial hero, Hero slider, Split banner, Video feature
  • 8 product display sections — Featured products, Product showcase, Product editorial, Product marquee, Product recommendations, Recently viewed, Shop the look, Collection list
  • 11 storytelling sections — Rich text, Image with text, Editorial scroll, Editorial mosaic, Editorial statement, Key ingredients, Clinical results, Before/after, Mood routines, Timeline, Stats
  • 4 gallery sections — Image gallery, Lookbook grid, Rhythm board, Room plan
  • 3 social proof sections — Testimonials, Brand logos, Social feed
  • 7 engagement sections — Newsletter, Contact form, FAQ, Comparison table, Features grid, Countdown, Blog carousel
  • 5 motion sections — Marquee, Horizontal scroll, Parallax image, Scroll text, Gradient divider
  • 8 site-wide sections — Announcement bar, Header, Footer, Age verifier, Maison promo popup, Popup, Cart notification, Custom section
  • 9 main page sections — main-product, main-collection, main-cart, main-blog, main-article, main-page, main-search, main-404, main-password
  • 2 section groups — header-group, footer-group

Product page

  • Editorial gallery with variant swatches, 3D model viewer, video, external video, and focal-point aware imagery
  • Up to 20 configurable info blocks — variant picker, swatches, quantity, buy buttons, Shop Pay Installments, Follow on Shop, complementary products, trust badges, delivery estimate, size guide, share, popups, tabs, custom Liquid, app blocks
  • Default and "with tabs" template variants — same product, different info layout
  • Sticky add-to-cart bar on mobile
  • Tax-included messaging and unit pricing for regulated regions

Cart & checkout

  • Cart drawer or full cart page (configurable per store)
  • Line-level and cart-level discount display
  • Free shipping progress bar with merchant-set threshold
  • Cart notes and gift wrapping as optional add-ons
  • Accelerated checkout buttons (Shop Pay, Apple Pay, Google Pay) via {% form 'cart' %}
  • Unit pricing display

Gift cards

  • Recipient form on the gift card product page — send a gift directly to someone else's email on a scheduled date
  • Custom-styled gift card display page with code, QR code, and Apple Wallet support
  • Personalized message field

Internationalization

  • Four shipped storefront locales — English (default), German, Spanish, French
  • Locale-aware hreflang alternates in the layout head
  • Country / language selectors in the footer and mobile drawer when Shopify Markets is enabled
  • Native Shopify multi-currency support

Performance

  • Critical CSS split out and loaded synchronously; non-critical CSS deferred
  • Font preloading via woff2 with crossorigin
  • LCP image preload and fetchpriority="high" on hero imagery
  • preload="metadata" on videos so they don't block paint
  • Responsive imagery with srcset across every image
  • All JavaScript deferred or async — 14 modular files (~109 KB total)
  • No external font services — uses Shopify's font CDN exclusively
  • No third-party libraries on the storefront beyond optional Lenis smooth-scroll (lazy-loaded)

Accessibility

  • WCAG 2.1 AA color contrast across all presets
  • Skip-to-content link, semantic <main role="main">, focus management on drawers
  • role="img" on rating stars, aria-hidden on decorative SVGs
  • Keyboard-reachable cart drawer, menu drawer, quick view, search
  • aria-live announcements for cart updates and search results
  • Respects prefers-reduced-motion across all animations

SEO

  • JSON-LD structured data for Product, Article, BreadcrumbList, and Organization
  • Open Graph and Twitter Card meta tags conditional on page type
  • Canonical URLs across all templates
  • hreflang alternates for locale variants
  • Default social share image and meta description configurable from theme settings

Technical foundation

  • Built on Shopify Online Store 2.0 — sections and blocks on every page
  • JSON-driven templates with editor presets
  • Native swatch object support (with color-name-to-hex fallback)
  • Focal-point aware responsive imagery via image.presentation.focal_point
  • Shopify selling plans for subscriptions — works with Shopify Subscriptions, Recharge, Loop, Bold
  • App block support in product, featured products, cart, and most content sections
  • Multi-level header navigation (up to two levels) with mobile drawer
