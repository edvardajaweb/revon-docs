Setup guide

Getting started

Install the theme, pick a style, and fill in the basics. About 20 minutes from start to a fully styled home page. The biggest decision is step 02 — which preset fits your brand best.

01 Install the theme

  1. Buy Revon from the Shopify Theme Store. It's added to your store library automatically.
  2. Go to Online Store → Themes in your Shopify admin.
  3. In the Theme library section, find Revon and click Add.
  4. Click Customize to open the theme editor.
Before you go live

Always duplicate your current published theme first. Go to Themes, click the three-dot menu on your live theme, and choose Duplicate. This gives you a clean rollback if anything goes wrong.

02 Choose a preset

Revon comes with three ready-made styles — Skincare, Atelier, and Maison. Each one is a complete look: fonts, colors, spacing, animations, and a finished homepage, all tuned to a different kind of brand. Maison is the default; switch to a different one before you start customizing.

  1. In the theme editor, click Theme settings (top-left).
  2. Open the Theme styles picker at the top.
  3. Pick Skincare, Atelier, or Maison.
  4. Save. Theme settings switch immediately; the homepage refreshes with the matching layout.
Which one?

Skincare for beauty / wellness / fragrance. Atelier for fashion / jewelry / leather. Maison for home / lifestyle / interiors. The Presets page has a full side-by-side comparison.

03 Set up essentials

Logo and favicon

  1. Open Theme settings → Logo.
  2. Upload your main logo. SVG is preferred; PNG works well if transparent.
  3. Upload a favicon under Theme settings → Favicon. Recommended 64×64px PNG.

Colors and typography

  1. Open Theme settings → Colors. Revon ships with a warm editorial palette you can override.
  2. Open Theme settings → Typography to change heading and body fonts. All Google Fonts and Shopify-hosted fonts are supported.

Navigation menus

  1. Go to Online Store → Navigation.
  2. Make sure a menu called Main menu exists — Revon uses it by default.
  3. For multi-level dropdowns, drop sub-items onto a parent item to nest them. Revon renders up to two levels.
  4. Create a Footer menu the same way; the footer section pulls from it by default.

04 Build your home page

When you applied a preset in step 02, Revon set up a curated homepage for you. Open the home page template in the editor and you'll see a stack of pre-configured sections. Click any section to edit its settings, click Add section to insert a new one, or drag to reorder.

Skincare homepage stack

Cinematic hero → Featured products → Product showcase → Before/after → Clinical results → Key ingredients → Collection list → Shop the look → Testimonials → Stats → Social feed → Image with text → FAQ → Newsletter.

Atelier homepage stack

Editorial hero → Lookbook grid → Featured products → Editorial mosaic → Shop the look → Editorial statement → Brand logos → Timeline → Testimonials → Newsletter.

Maison homepage stack

Cinematic hero → Featured collections → Editorial scroll → Rhythm board → Room plan → Featured products → Parallax image → Testimonials → Newsletter.

Mix freely

Every section works in every preset. You can pull the Clinical results section into the Atelier preset, or drop a Lookbook grid into Maison. The preset is your starting point, not a rulebook.

05 Configure product pages

  1. Open a product in the theme editor via Product pages in the template picker.
  2. Each piece of the product info column is a block — drag to reorder, or remove anything you don't need.
  3. To display product variants as colored swatches, add a color or image metafield on the variant option and Revon will render them automatically.
  4. To show a 3D model, upload a .glb file to your product's media. Revon will render it with the Shopify model viewer.

06 Cart and checkout

Revon supports both cart drawer and cart page modes. Choose which under Theme settings → Cart. Both modes include:

  • Automatic discount code display
  • Order notes
  • Free-shipping progress bar
  • Unit price display for regulated regions
  • Accelerated checkout buttons (Shop Pay, Apple Pay, Google Pay)

07 Go live

  1. Preview your theme thoroughly on desktop and mobile.
  2. Click Publish from the theme editor or the Themes page.
  3. Check the live site in an incognito window to confirm everything renders without your admin session.

Support policy

What's included

  • Bug fixes in Revon's code
  • Answers to questions about theme features and settings
  • Guidance on using Shopify features supported by Revon

What's not included

  • Custom code modifications to your theme
  • App integrations without an app block
  • Help with third-party apps or services
  • Content creation, SEO consulting, or marketing advice

Head to the FAQ or contact support. We reply within two business days.
