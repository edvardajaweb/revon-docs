Getting started

Use this order to build a complete Revon store without redoing work. Finish the structure first, connect real store data second, add imagery third, and test every customer path before publishing.

01 Install the right preset

  1. Open Revon in the Shopify Theme Store.
  2. Compare the Pure, Atelier, and Maison listings and demo stores.
  3. Select Try theme from the preset that is closest to your industry and desired layout.
  4. Open the installed draft from Online Store > Themes.
  • Pure: beauty, wellness, personal care, supplements, and fragrance.
  • Atelier: fashion, jewelry, accessories, and leather goods.
  • Maison: furniture, home goods, lighting, ceramics, and interiors.

Pure is Revon's default preset. Atelier and Maison include separate preset-level template files, so installing either preset gives you its matching homepage, product page, About page, header, and footer.

02 Prepare safely

  1. Keep Revon unpublished while you configure it.
  2. Duplicate the draft before changing theme style or editing code.
  3. Use the theme editor's preview controls to check desktop and mobile.
  4. Do not delete your current published theme. Shopify keeps products and orders separate, but theme settings and layouts belong to each theme copy.
Demo content

Demo products, collections, and imagery are not transferred into your store. Revon provides the layout and editable starter copy; you connect your own store resources and licensed images.

03 Add your brand system

Logo and favicon

  1. Open Theme settings > Logo and branding.
  2. Upload a transparent SVG or high-resolution PNG logo.
  3. Upload a square favicon and preview it in a browser tab.
  4. Open the Header section and check logo scale on desktop and mobile.

Colors

  1. Open Theme settings > Colors.
  2. Edit the light and dark color schemes to match your brand.
  3. Set sale, success, warning, error, and fallback swatch colors.
  4. Preview links, buttons, forms, badges, unavailable states, and dark sections.

Typography and layout

  1. Open Theme settings > Typography and select fonts through Shopify's font picker.
  2. Adjust heading weight, size, transform, and tracking only after testing long headings.
  3. Keep the default 1440px page width initially. The control supports 1000-1600px.
  4. Adjust desktop and mobile spacing separately.

04 Connect navigation and footer

  1. In Shopify admin, open Content > Menus.
  2. Create or review the main menu and footer menus.
  3. Create products, collections, pages, or policies before linking to them.
  4. Nest menu items carefully and test both desktop dropdowns and the mobile drawer.
  5. In the theme editor, open Header and select the main menu.
  6. Open Footer and connect menus, newsletter, social links, payment icons, and localization controls.

05 Prepare products and collections

  • Use clear product titles, descriptions, prices, inventory, vendors, and product types.
  • Add meaningful image alt text and consistent image ratios.
  • Add product videos, external videos, or 3D models only when they help customers inspect the product.
  • Create option values and native swatches for colors or materials.
  • Configure selling plans, quantity rules, volume pricing, unit pricing, and local pickup when relevant.
  • Create automated or manual collections, then connect them to navigation and homepage sections.
  • Test one available product, one sold-out product, one sale product, one multi-option product, and one gift card.

06 Build the main templates

Use the template picker at the top of the theme editor. Start with these templates:

  • Home page: connect every product, collection, image, video, page, and CTA. Remove sections you do not need.
  • Default product: reorder product information blocks and verify media, variants, buying options, pickup, and recommendations.
  • Collection: set grid density, filtering, sorting, image ratio, and pagination.
  • Cart: configure notes and review empty and populated states.
  • Search: verify predictive search and the full results page.
  • About, contact, and FAQ pages: create the Shopify pages, then assign the matching theme template.
  • Blog and article: add realistic article content and test long titles and rich text.
  • Password and 404: replace starter copy and check links.

See Presets for the exact homepage and supporting template stack installed by Pure, Atelier, and Maison.

07 Configure cart and checkout handoff

  1. Open Theme settings > Cart.
  2. Select drawer, notification, or page behavior.
  3. If using the shipping-progress message, enter the threshold and create the matching shipping rate in Shopify.
  4. If using gift wrapping, understand that Revon saves gift-wrap and gift-message cart attributes; it does not charge a fee automatically.
  5. Run an add-to-cart test, change quantities, remove lines, enter a note, and continue to checkout.
  6. Check discount allocations, selling-plan lines, line-item properties, unit prices, and accelerated checkout buttons when available.

08 Configure markets, languages, and apps

  • Configure Shopify Markets, currencies, languages, domains, product availability, and pricing in Shopify admin.
  • Enable country and language selectors in the Header or Footer when your store serves multiple markets.
  • Revon includes English, German, Spanish, and French locale files. Review translations for your store's terminology.
  • Install only the apps required for launch.
  • Use app blocks in supported sections or app embeds from the theme editor.
  • Test every app on product, cart, account, and mobile screens before publishing.

Read App integrations before installing reviews, subscriptions, loyalty, wishlists, chat, or advanced search.

09 Test and publish

  • Preview Chrome, Safari, Firefox, Edge, iPhone, and Android layouts.
  • Navigate with a keyboard and confirm visible focus on every link, button, form, drawer, and modal.
  • Test at 200% browser zoom and with reduced motion enabled.
  • Test home, product, collection, search, cart, page, blog, article, account, password, gift card, and 404 pages.
  • Test empty, loading, error, unavailable, sold-out, and long-content states.
  • Check that every image is licensed, sharp, correctly cropped, and has useful alt text.
  • Confirm all discounts, results, awards, reviews, shipping statements, and policies are real.
  • Place a test order using Shopify's test payment setup.
  • Publish only after testing the final draft in an incognito window.
Need help?

Use the support form and include your store URL, theme version, page URL, browser, steps to reproduce, and screenshots.
