Support policy

What's included

  • Bug fixes in Revon's code
  • Answers to questions about theme features and settings
  • Guidance on using Shopify features supported by Revon
  • Help interpreting error messages related to Revon

What's not included

  • Custom code modifications to your theme
  • App integrations that don't ship with an app block
  • Help with third-party apps or services
  • Content creation, SEO consulting, or marketing advice
  • Help with theme updates when you've modified code

Response times

We reply to every support request within two business days (Monday–Friday, excluding public holidays). Critical bugs that affect multiple merchants are prioritized and usually patched within 24 hours.

Before editing code

Always duplicate your theme before editing code. Go to Online Store → Themes, click the three-dot menu on your theme, and choose Duplicate. This gives you a rollback if something breaks. If you're not comfortable with Liquid, hire a Shopify Partner — support requests that require us to modify merchant-owned code are outside the scope of free support.
