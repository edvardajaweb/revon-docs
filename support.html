Check the FAQ and the Customizing guide — most questions are answered there. If you're stuck on a code customization, we can walk you through it but we can't edit your store's code for you.

Support policy

What's included

  • Bug fixes in Revon's code
  • Answers to questions about theme features and settings
  • Guidance on using Shopify features supported by Revon
  • Help interpreting error messages related to Revon

What's not included

  • Custom code modifications to your theme
  • App integrations that don't ship with an app block
  • Help with third-party apps or services
  • Content creation, SEO consulting, or marketing advice
  • Help with theme updates when you've modified code

Response times

We reply to support requests within two business days, Monday-Friday excluding public holidays. Confirmed theme bugs are prioritized by severity and included in an appropriate maintenance release.

Before editing code

Always duplicate your theme before editing code. Go to Online Store → Themes, click the three-dot menu on your theme, and choose Duplicate. This gives you a rollback if something breaks. Support requests that require us to modify merchant-owned code are outside the scope of free support — consider hiring a Shopify Partner.
