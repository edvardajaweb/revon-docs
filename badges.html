Product badges

Create product-specific labels, control automatic status badges, and keep product-page trust messaging accurate. This guide explains every badge source in Revon and the exact scope of each setting.

Recommended method

Use the custom.badge product metafield for permanent merchant-managed labels. Use badge: product tags only as a quick fallback. Metafields provide a clearer admin field and are easier for a team to manage consistently.

Understand the four badge types

Badge typeSourceWhere it appearsLimit
Custom card badgecustom.badge metafield or badge: tagShared product cardsTwo per product
Automatic statusAvailability, compare-at price, or new tagShared product cardsOne per product
Image badgeProduct template settingMain product gallery imageOne per template
Trust badgesProduct template blockProduct information areaThree per template

Custom card badges are product data, so different products can show different labels while using the same template. Image and trust badges are template content, so every product assigned to that product template receives the same wording.

Quick setup with product tags

Use this method when you need a badge immediately and do not yet want to create a metafield definition.

  1. From Shopify admin, open Products and select a product.
  2. Find the product's Tags field.
  3. Add a tag using badge: followed by the exact customer-facing label. Example: badge:Limited edition.
  4. Optional: add a second tag such as badge:Vegan.
  5. Save the product and preview a collection or search-results page.

The badge: prefix is not displayed. Revon reads up to two matching tags and displays only the text after the colon. Prefix matching is case-insensitive, but using lowercase badge: keeps product data consistent.

Tag fallback rule

When a product has a non-empty custom.badge metafield, metafield values take priority and all badge: tags are ignored for that product.

Recommended metafield setup

Create one definition for the store. Afterward, every product receives a clearly named Custom badge field in Shopify admin.

Option A: one custom badge per product

  1. From Shopify admin, open Settings > Metafields and metaobjects.
  2. In Metafield definitions, select Products.
  3. Select Add definition.
  4. Enter Custom badge for the name.
  5. Open Namespace and key and enter exactly custom.badge.
  6. For the type, select Single line text and keep it as one value.
  7. Add a maximum-length validation of 32 characters.
  8. Enable Storefronts access when the Access option is shown.
  9. Pin the definition so it appears directly on product pages, then save.

Option B: up to two custom badges per product

Follow the same steps, but enable List of values for the Single line text type. Revon reads the list in its saved order and displays the first two non-empty values. Choose the one-value or list structure before a team starts entering data so every product follows the same workflow.

Shopify documents the current admin process in Creating custom metafield definitions and explains list fields in Metafield lists.

Add or remove badge values

  1. From Shopify admin, open Products and select the product.
  2. Scroll to the product's Metafields area. Select View all when the pinned field is not visible.
  3. Open Custom badge.
  4. Enter one short label, or add and order up to two list values.
  5. Save the product.
  6. Preview a storefront location that uses product cards.

Leave the metafield empty and remove any badge: tags when a product should have no custom badge. Badge text is escaped before output and limited to 32 displayed characters. Revon does not render empty values.

Good label examples

  • Pure: Vegan, Fragrance-free, Refillable.
  • Atelier: Limited run, Made to order, Exclusive color.
  • Maison: Solid oak, Hand finished, Made to order.

Use only wording that is accurate for that product. Keep evidence for certification, sustainability, material, clinical, discount, availability, and production claims.

Bulk edit badges

After the metafield definition exists, Shopify's bulk editor can update many products without opening each product page.

  1. From Shopify admin, open Products.
  2. Select the products you want to update.
  3. Select Bulk edit.
  4. Open Columns, find Metafields, and enable Custom badge.
  5. Enter or remove values in the Custom badge column.
  6. Save, correct any validation errors, and preview representative products.

See Shopify's bulk metafield editing guide for the latest bulk-editor controls.

Appearance and display rules

  1. Open Online Store > Themes and select Customize on a draft copy of Revon.
  2. Open Theme settings > Product cards > Badges.
  3. Use Show custom badges to enable or disable all metafield and tag badges.
  4. Choose Custom badge background and Custom badge text colors.
  5. Save and check contrast in every preset and color scheme used by the store.

Custom badge colors are global. Individual products control wording, not color. All labels remain sharp-cornered and use the compact product-card typography.

Where custom badges appear

  • Collection product grids.
  • Search results.
  • Featured products that use Revon's shared card.
  • Product recommendations.
  • Other theme sections that render the shared product-card component.

The custom.badge value does not appear inside the main product information area. Use the Image badge or Trust badges controls for product-page messaging.

Stacking and priority

A card can show up to two custom badges plus one automatic status badge. Automatic status uses the following order:

  1. Sold out: product availability is false.
  2. Sale: a valid compare-at price is higher than the selling price and Show sale badge is enabled.
  3. New: Show new badge is enabled and the product has the exact tag new or New.

Only one automatic status appears. Custom labels remain separate, so a product can show "Limited edition" together with a real Sale percentage.

Product-page image and trust badges

Image badge

  1. Open the required product template in the theme editor.
  2. Select Product information.
  3. Enter text in Image badge text.
  4. Save. The label appears on the main gallery image only.

This is template-level content. Every product assigned to that product template receives the same image badge. Use alternate product templates for groups such as Made to order or Pre-order.

Trust badges

  1. Inside Product information, add or select the Trust badges block.
  2. Edit up to three labels.
  3. Choose an icon for each: lock, shield, truck, refresh, heart, star, check, or leaf.
  4. Clear an item's text to hide it and drag the block to the required position.

Trust badges are also template-level. Make sure shipping, returns, security, sustainability, and material statements match the store's real policies and product data.

Troubleshooting

The custom badge does not appear

  • Confirm Show custom badges is enabled.
  • Confirm the namespace and key are exactly custom.badge.
  • Confirm the product value is saved and not empty.
  • For tag fallback, confirm the tag begins with badge: and contains text after the colon.
  • Confirm you are viewing a theme card rather than an app-provided product card.
  • Refresh the storefront preview after saving product data.

The tag badge is ignored

Check the product's Custom badge metafield. Any non-empty metafield value takes priority over all badge: tags. Clear the metafield when tags should be used instead.

Only two custom badges appear

This is intentional. Revon limits each card to two custom labels to protect image visibility and prevent layout overflow. Move lower-priority information into the product description, image badge, or trust block.

Text is shortened

Custom card labels are limited to 32 displayed characters. Rewrite the label as a short customer-facing fact instead of increasing the badge size.

The wrong automatic badge appears

Sold out overrides Sale and New. Sale overrides New. Check product availability, compare-at pricing, the exact new or New tag, and the Sale/New toggles in Product cards.

Badge testing checklist

  • Test no custom badge, one badge, and two badges.
  • Test metafield values and tag fallback separately.
  • Test a product that has both sources and confirm the metafield wins.
  • Test custom plus Sold out, Sale, and New states.
  • Test the longest permitted wording on narrow mobile cards.
  • Check color contrast and keyboard focus on card links.
  • Check collection, search, featured, and recommendation cards.
  • Check every language and translate customer-facing badge values where required.
  • Verify every badge claim against real product data and policies.
