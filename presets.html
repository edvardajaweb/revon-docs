Docs Presets

Three voices, one theme

Presets.

Revon ships with three named presets — Skincare, Atelier, and Maison. Each preset is a complete configuration: typography, color palette, spacing rhythm, animation style, and a curated homepage. Pick one and you have an industry-tuned storefront; the rest of the theme adapts.

What is a preset?

A preset is a named bundle of theme settings stored under config/settings_data.json. When you apply a preset, Shopify swaps every theme setting (fonts, colors, spacing, animation, cart type) to that preset's values, and Revon swaps in the matching homepage layout from listings/<preset>/. Sections, snippets, and code stay shared across all three.

Why three?

Because a beauty brand, an indie fashion house, and a homewares boutique each speak in a different visual language — and most theme libraries make merchants do that translation themselves. Revon's presets are pre-translated.

Skincare

Vertical: Beauty, wellness, supplements, fragrance.

Aesthetic: Confident, clinical, optimistic. Big bold sans-serif headings, warm cream background, decisive uppercase tracking. Designed to make ingredient stories and clinical results feel earned rather than over-promised.

Typography

  • Headings: Manrope extrabold (800), uppercase, tight letter-spacing (−3)
  • Body: Manrope regular, 16px, generous line-height
  • Display size: 48px base, scales up to 96px on the hero

Atelier

Vertical: Slow fashion, capsule wardrobes, leather goods, jewelry.

Aesthetic: Quiet, considered, made-to-last. Light Cormorant serif, paper-grey background, generous whitespace. Less shouting, more breathing — the opposite of fast fashion's saturation.

Maison

Vertical: Home, interiors, ceramics, scent, lifestyle.

Aesthetic: Warm, lived-in, refined. Noto Serif body that reads like a print monograph, sage-cream palette, gently rounded corners. Designed for tactile products where the object's surface and the room around it both matter.

Which one to choose

If you're not sure, this is a quick decision tree:

  • You sell things people put on or in their body (skincare, cosmetics, supplements, fragrance) — start with Skincare.
  • You sell things people wear (clothing, jewelry, accessories) — start with Atelier.
  • You sell things people put in their home (homewares, ceramics, candles, interiors) — start with Maison.

All three presets share the same 62 sections under the hood — so you can move sections across presets, mix and match, or evolve from one starting point into something entirely your own. The preset is a starting line, not a cage.

Applying a preset

From the theme editor (recommended)

  1. Open Online Store → Themes → Customize.
  2. Click Theme settings in the top-left of the editor.
  3. Open the Theme styles picker at the top.
  4. Choose Skincare, Atelier, or Maison.
  5. Save. The theme settings switch immediately; the homepage may take a refresh.
Heads up

Applying a preset overwrites your current theme settings (colors, fonts, spacing, etc.). It does not overwrite section content you've added or edited. Always duplicate your theme first if you've already done customization work.

From the Shopify CLI (developers)

If you're working with the theme locally and want to push a specific preset's homepage layout to a demo store:

# Skincare — uses the base templates
shopify theme push --store=your-store.myshopify.com

# Atelier — applies listings/atelier/ overrides
shopify theme push --store=your-store.myshopify.com --listing=atelier

# Maison — applies listings/maison/ overrides
shopify theme push --store=your-store.myshopify.com --listing=maison

Mixing & customizing

A preset is the start of your design, not the end. After applying one you can:

  • Swap the heading or body font to anything in the Shopify font picker.
  • Override colors via the theme editor — your changes win over preset defaults.
  • Add sections from any preset's signature list — they all work on any preset.
  • Use both color schemes (light + dark) on the same page via per-section settings.
  • Save your changes as a custom preset by adding a new entry under config/settings_data.json → presets.
